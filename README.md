# 禅道工作台 · dsh-zentao

DeepSeek Harness 原生插件，在独立侧栏工作台查看禅道任务、Bug、详情和未读通知，并通过可选的 dsh-pet 桌宠提示新指派事项。

## 功能

- 任务与 Bug 支持“我的/全部”、关键字、状态、优先级筛选和分页；页签徽标统计当前账号的个人事项总数。
- 详情包含描述、操作记录、评论、工时、截图与附件，并提供打开禅道原页面的入口。
- 后台默认每 45 秒同步，可配置 30～60 秒；首次成功同步建立基线，后续检测新建、指派及重新指派。
- 通知持久保存，已读与桌宠投递状态独立；桌宠暂不可用时保留未读。
- 支持浅色/深色主题及独立主区域布局，兼容可选 liang 皮肤的背景层。
- 用户在界面填写自己的禅道网址、账号和密码；仓库及安装包不预置任何个人连接。

## 运行要求

- DeepSeek Harness：目标版本 `0.2.1-rc.5`，插件引擎范围以 `package.json` 为准。
- Node.js：`>=22.12.0`，推荐 Node 24。React 由 DSH 提供，无需单独安装运行时依赖。
- 禅道须提供兼容的 `/api.php/v1` REST API 和账号密码令牌登录，账号应具备相关项目及产品的读取权限。
- 桌宠气泡为可选功能，需要 dsh-pet `0.4.0` 或兼容版本并启用桌面显示。仅需一只桌面宠物时选“仅桌面”；“网页和桌面”会在两个位置显示同一只宠物。

## 从源码构建安装包

```sh
git clone https://github.com/autharfei/dsh-zentao.git
cd dsh-zentao
node scripts/pack.mjs
```

命令会先构建 Host/Client，再生成 `dist/dsh-zentao-0.1.5.tgz`，同时输出包大小、文件清单和 SHA-256。

在 DSH 的「插件 → 添加插件」中填生成的 `.tgz` 文件绝对路径，安装并启用。已经安装旧版时，按 DSH 第三方插件的卸载/重装流程更新；是否需重启以宿主提示为准。

本仓库不跟踪生成的 `lib/` 和 `dist/`，下载源码后请先执行构建。GitHub 自动生成的源码 ZIP 不等于可直接安装的插件包。若维护者另行发布 Release 安装附件，可下载该 `.tgz` 使用。

## 首次配置

1. 从 DSH 侧栏打开「禅道」，首次未配置时会直接进入连接设置。
2. 填写自己的禅道应用根地址、账号和密码，点击「保存连接」。
3. 保存会验证登录；成功后开启后台同步。失败会保留之前的有效连接。

地址示例：`https://zentao.example.com/zentao`。支持 HTTP/HTTPS、域名、IP、自定义端口及应用子路径；不要填写登录页面或 `/api.php/v1` 本身。局域网、自建服务器和云服务器均可，前提是运行 DSH 的电脑能访问目标地址、HTTPS 证书受信任、API 与登录方式兼容。仅提供 SSO 或不同 API 的 SaaS 不保证直接兼容。

已保存的同一网址和账号，密码留空表示保留原密码；更换网址或账号需要重新填写密码。页面可显示本人保存的网址、账号，但不回显密码或 Token。

## 本地数据与隐私

- 不自动读取禅道 MCP 或环境变量中的登录信息，也不预置默认站点或账号。
- 本人填写的连接保存在 `$DSH_HOME/storages/dsh-zentao/connection.json`；任务快照与通知在同目录的 `state.json`。未设置 `DSH_HOME` 时使用当前用户主目录的 `.dsh`。
- 密码以本机连接配置形式保存，不是操作系统密码保险库；请保护该目录的访问权限。密码和 Token 不放入客户端响应、通知状态或安装包。
- 重新启动或升级会读取本人已保存的插件配置；将安装包分享给他人不会分享这些本地配置。
- 富文本在禁脚本沙箱中展示，截图使用受控的同源附件代理，不向浏览器传递禅道登录凭据。
- `.gitignore` 排除本地连接、环境文件、运行数据、日志、调试与生成产物。提交前仍需检查暂存区，避免把真实业务样本或凭据放进其他文件。

## 桌宠提醒定制

在「设置 → 同步与提醒」中可为任务和 Bug 分别设置：

- 已安装桌宠提供的动作；动作播放时长由桌宠决定。
- 头顶气泡图片：桌宠表情池、上传的 PNG/JPEG/GIF/WebP，或可由桌面直接访问的 HTTP/HTTPS 图片地址。
- 气泡显示时长 5～120 秒，默认 10 秒。文字会和图片一起显示，气泡外形由 dsh-pet 负责。

上传图片只保存在本机插件存储目录，使用随机访问标识提供给桌面宠物读取；不会进入禅道、GitHub 或安装包。桌面宠物没有 DSH 浏览器登录态，因此图片网址必须是桌面端可直接访问的 HTTP/HTTPS 地址。睡眠中的桌宠、被其他联动占用的桌宠可能暂时拒绝动作；插件会保留通知并在下一轮重试。任务和 Bug 同时到达时会按类别依次展示，避免气泡立即覆盖。

## 通知语义与限制

首次同步不提示历史事项；后续新指派按批次合并。通知按站点与账号隔离，未读不自动删除，已读保留最近 500 条。

桌宠“已投递”表示接口受理，不保证气泡持续显示；其他桌宠内容可能覆盖气泡，完整记录以插件通知列表为准。DSH 退出后停止同步。本插件不修改禅道业务记录，不包含桌宠气泡点击跳转或独立 Windows 系统通知。

## 开发命令

```sh
node scripts/build.mjs
node scripts/pack.mjs
```

需要自行执行测试时：

```sh
node --test --test-isolation=none
```

测试数据中的账号、密码与域名均为合成样本。浏览器检查按需启用，默认跳过；详见 [开发说明](docs/development.md)。手动联网检查脚本 `scripts/verify-live.mjs` 会使用本机已保存的插件连接，只输出数量和字段概况；不会在构建或普通测试中自动运行。

接口契约见 [Host/Client contract](docs/contract.md)。当前源码版本为 `0.1.5`；本仓库公开整理不代表对该版本执行了新一轮功能测试或安装验收。
