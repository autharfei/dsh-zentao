# 界面样式说明 · 0.1.8

本版沿用整页可读性优化，并修正页签区不必要的纵向滚动条，以及链接包裹的重现步骤截图被富文本清理误删的问题。截图仍通过既有图片代理读取，接口权限或不支持的原图地址不在此修补的确认范围内。

## 字体与重点

| 内容 | 字号 | 处理 |
|---|---:|---|
| 正文、输入、任务/Bug标题 | 14px | 长说明保持常规字重，事项标题加粗 |
| 表格内容、列头、次级导航 | 13–14px | 列头与导航按钮加粗，主次明确 |
| 状态、日期、辅助说明、行内动作 | 12–13px | 提高原有10–11px文字的可读性，动作加粗 |
| 详情与设置分区标题 | 16–20px | 加粗，与正文拉开层级 |
| 页面标题 | 26px，极窄容器24px | 加粗 |
| 指标数字 | 30px，窄容器26px | 加粗、等宽数字 |

基础行距1.6，说明和富文本约1.75–1.8。字体现有系统字体优先，不加载外部字体。

## 布局与操作

- 主要按钮、搜索和筛选控件高度38px；行内动作至少30px，小分页/关闭按钮至少32px。
- 表头44px，内容行基础78px并随长标题和更多操作自然增高；列间距更宽，选中行保留侧边强调线。
- 操作栏以边界区分，按钮有留白与悬停反馈。取消使用警示色，完成/解决使用成功色，所有动作保留文字标签。
- 详情、通知、设置分组和操作弹窗统一标题、标签、辅助说明的字重与间距。
- 保留浅色/深色主题，边框对比略加强，键盘焦点可见。
- 容器较窄时筛选换行、表格和导航横向滚动；详情改用覆盖抽屉，避免列表与详情双栏挤压。表单在窄容器改为单列。

本版不新增业务操作，0.1.6的操作范围与限制继续适用，见 [操作能力说明](operations.md)。

## 用户更新与人工检查清单

按DSH现有第三方插件更新流程使用0.1.8安装包，按宿主提示刷新或重启后打开禅道工作台。安装卸载由用户操作。

1. 在任务/Bug页检查标题、列头和按钮是否清楚；切换筛选、分页、长标题和操作“更多”时，文字与按钮完整可达。
2. 打开详情与操作表单，检查字段标签、输入值、辅助说明、关闭和底部按钮；仅检查样式即可，不必为了验收提交真实业务操作。
3. 切换浅色/深色主题，查看选中行、禁用按钮、语义颜色及Tab键焦点。
4. 缩窄工作区，检查筛选换行、表格/导航横向滚动、详情抽屉、单列表单；再检查通知、连接和桌宠设置中的文字与控件。

本轮交付依据源码静态审查、JavaScript语法检查、构建打包及归档内容检查；未运行功能测试、GUI验收或安装卸载。以上人工检查尚待用户执行。
